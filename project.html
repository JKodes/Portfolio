Asteroid

Asteroids is a Python-based remake of the classic 1979 arcade game, built using the Pygame library. Players control a spaceship, dodging or shooting asteroids to survive in space. Inspired by nostalgia and created during the pandemic, this project brought a beloved childhood game back to life—fully offline and customizable.

Bestbuy Bot

Best Buy Bot is an automated script built with Python and Selenium to secure high-demand PlayStation 5 consoles during limited online restocks. Frustrated by resellers and random drop times, I created this bot to quickly navigate the site, add the console to the cart, and proceed to checkout. Originally built in 2021 and later revamped using OOP in 2022, this project taught me automation, clean code practices, and problem-solving in real-world scenarios.
